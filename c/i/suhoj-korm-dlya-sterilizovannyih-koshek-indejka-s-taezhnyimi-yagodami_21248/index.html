Описание

Сухой корм для стерилизованных кошек и кастрированных котов Pets ministry с индейкой. Корм для кошек сухой подходит для ежедневного кормления после стерилизации и учитывает сниженный уровень активности взрослых кошек.

Сухой корм для кошек с индейкой содержит легкоусвояемый животный белок, необходимый для поддержания мышечной массы и физической активности без избыточной нагрузки. Индейка подходит для регулярного кормления стерилизованных кошек и кастрированных котов.

Таёжные ягоды дополняют корм для кошек сухой натуральными витаминами и антиоксидантами, способствуют поддержанию иммунитета и общего самочувствия питомца. Сбалансированный состав делает сухой корм для кошек подходящим для повседневного рациона после стерилизации.

Состав

Животные ингредиенты 38 % (дегидрированное мясо индейки 28%, топленый жир 7%, гидролизат животного белка 3%), рис, кукуруза, льняное семя и лососевый жир (источники омега-З), ягода таежная: облепиха, клюква, шиповник (источники витаминов группы С), комплекс витаминов и минералов, пивные дрожжи (источник витаминов группы В), яичный порошок, таурин, L-карнитин, DL-метиинин, пробиотический комплекс (Bacillus subtilis, Bacillus licheniformis), пребиотики (МОС, корень цикория). Сохранено экстрактом розмарина и витамином Е.
